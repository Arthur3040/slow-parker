# Slow Parker 2099 — Miguel O'Hara Edition | Flyer Técnico Digital

Site em formato de **flyer técnico digital** responsivo (Desktop & Mobile) para apresentar o robô **Slow Parker** (*Rope Climbing Monkey* em versão bicho-preguiça fantasiado de **Homem-Aranha 2099 / Miguel O'Hara**).

## Como subir as fotos do "Depois" pelo celular no GitHub
O código (`index.html`) já está pré-configurado esperando exatamente estes 3 arquivos dentro da pasta `assets/`:
- `assets/depois-01.jpg`
- `assets/depois-02.jpg`
- `assets/depois-03.jpg`

Para enviar de última hora pelo celular:
1. Renomeie as 3 fotos no celular para `depois-01.jpg`, `depois-02.jpg` e `depois-03.jpg`.
2. Abra o repositório no navegador do celular ou app do GitHub e entre na pasta `assets/`.
3. Toque em **Add file > Upload files**, selecione as 3 fotos e confirme em **Commit changes**.
4. Assim que o GitHub Pages atualizar (cerca de 1 minuto), as 3 fotos aparecerão automaticamente nos quadros da **Fase 02: Depois**.
